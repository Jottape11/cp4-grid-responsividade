# CP4 - Grid Layout & Responsividade

Projeto desenvolvido para a disciplina de Front-End Design (1ESPW - 2026).
O objetivo é criar uma página responsiva com duas seções utilizando CSS Grid Layout, sem frameworks.

## Integrantes do Grupo
- **João Pedro** - RM570509
- **Gustavo Louro** - RM570708

## Estrutura do Projeto
- **Seção 1**: Hero com imagem principal, texto com botão "Saiba mais" e galeria de 3 fotos secundárias usando `grid-template-areas`.
- **Seção 2**: Galeria de fotos de praia em grid de 5 colunas x 2 linhas usando `minmax()` e itens que ocupam 2 linhas com `grid-row: span 2`.
- **Responsividade**: Adaptação para telas desktop e mobile.

## Como executar
Basta abrir o arquivo `index.html` em qualquer navegador web.
